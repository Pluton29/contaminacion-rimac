# 🌊 Contaminación del Río Rímac

**Una aplicación interactiva que muestra cómo los metales de las minas afectan el agua de Lima**

---

## 📖 Descripción

Esta aplicación visualiza los efectos acumulativos de metales pesados provenientes de la actividad minera en los Andes sobre la calidad del agua del Río Rímac, que abastece a 8 millones de personas en Lima.

## 🎯 Características

- **📊 Visualización interactiva** de niveles de contaminación
- **⚙️ Controles ajustables** para actividad minera y tratamiento de agua
- **📈 Gráficos en tiempo real** de la evolución de metales
- **⚠️ Sistema de alertas** por niveles de riesgo
- **🔬 Información científica** sobre metales pesados

## 🧪 Metales Analizados

| Metal | Límite Seguro | Riesgo para la Salud |
|-------|---------------|---------------------|
| Plomo | 0.05 mg/L | Daño cerebral en niños |
| Zinc | 5.0 mg/L | Problemas digestivos |
| Cobre | 2.0 mg/L | Problemas hepáticos |
| Manganeso | 0.1 mg/L | Problemas neurológicos |

## 🚀 Cómo Usar la Aplicación

1. **Selecciona un metal** del menú desplegable
2. **Ajusta la actividad minera** con el control deslizante
3. **Modifica el nivel de tratamiento** de agua
4. **Observa en tiempo real** cómo cambian los niveles de contaminación
5. **Revisa las alertas** de riesgo para la salud

## 📊 Interpretación de Resultados

- **🟢 VERDE**: Niveles seguros (por debajo del límite)
- **🟡 AMARILLO**: Alerta baja (cerca del límite)
- **🟠 NARANJA**: Riesgo moderado (excede límite)
- **🔴 ROJO**: Alto riesgo (muy por encima del límite)

## 🎓 Base Científica

Este modelo se basa en investigaciones sobre:
- Efectos acumulativos de metales pesados
- Datos de monitoreo 2004-2010 del Río Rímac
- Estudios de calidad de agua potable en Lima

## 🔧 Tecnologías Utilizadas

- **Python** con Streamlit para la interfaz web
- **Pandas & NumPy** para análisis de datos
- **Matplotlib** para visualizaciones
- **Modelado científico** de contaminación acumulativa
